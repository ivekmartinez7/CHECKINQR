Conectar otros Dispositivos

Todos los dispositivos deben estar en la misma red Wi-Fi o conectados al Hotspot de este equipo. La conexión es HTTPS (cifrada).

1
Conecta todos los dispositivos a la misma red Wi-Fi o comparte Internet vía Hotspot desde este equipo principal.
2
Selecciona tu IP de Wi-Fi local abajo y escanea el código QR desde el otro dispositivo.
{% for ip in ips %} {{ ip }} {% endfor %}

URL para otros dispositivos:
https://{{ ips.0 }}/

Escanea para abrir la app
⚠️ Nota Docker: Las IPs 172.x.x.x son internas del contenedor. Usa tu IP Wi-Fi real.
Windows: Ejecuta ipconfig → busca "Dirección IPv4" de Wi-Fi.
Android: Ajustes → Acerca del teléfono → Estado → Dirección IP.

💡 Al abrir la URL, el navegador mostrará una advertencia de certificado. Selecciona "Avanzado" → "Continuar de todas formas". Es normal con certificados autofirmados.
3
Inicia sesión con cuentas del personal: Una vez conectados, los operadores deben iniciar sesión con las credenciales que configures a la derecha.
